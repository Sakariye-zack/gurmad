# Map, GPS & Routing

## Admin map layers
- Zone boundaries
- Registered houses
- Customer locations
- Live trucks
- Driver/collector assignment
- Planned route
- Completed houses
- Remaining houses
- Missed houses
- Route history

## Truck popup
Truck, plate, zone, driver, collector, route, completed/remaining houses, current location, GPS last update and status.

## Zone map
Zone Chairman sees assigned zone only.

## Route planning
Group nearby houses and respect truck capacity, zone and schedule.

## Technologies
Leaflet/react-leaflet for map rendering; Google Maps API for geocoding.

## Live monitoring
Socket.IO can update truck positions and operational progress in real time.
