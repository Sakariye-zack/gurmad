# 45. Page & Feature Inventory

## Dashboard
KPIs, charts, alerts, revenue, expenses, debts, tasks, fleet and live operations.

## Customers
List, search, filter, create, edit, profile, house, GPS, service history, invoices, payments, debt and documents.

## Zones
Create, edit, staff, trucks, customers, houses, tasks, map and zone reports.

## Collection Tasks
Create batch, capacity check, select truck/driver/collector(s), select houses, route, schedule, status and history.

## Operations Map
Zone/house/customer/truck layers, route, live GPS, task progress and history.

## Cashier
Assigned customer portfolio, invoice, balance, payment, receipt, debt list and cashout submission.

## Head of Cashiers
Cashier collections, cashout review, expected/actual, variance, approval, signatures and archive.

## Accounting
Chart of Accounts, journals, ledger, AR, AP, Trial Balance, P&L, Balance Sheet, Cash Flow.

## Documents
Invoice, receipt, quotation, cashout, expense, purchase documents, agreements and archive.

Every page must document purpose, fields, actions, filters, permissions, API and related database entities.
