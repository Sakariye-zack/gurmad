# 47. Financial Controls Matrix

| Activity | Cashier | Head of Cashiers | Accountant | Admin |
|---|---|---|---|---|
| View assigned customer balance | Yes | Yes | Yes | Yes |
| Record customer payment | Yes | Review | View | Yes |
| Submit cashout | Yes | Review | View | Yes |
| Approve cashout | No | Yes | According to policy | Yes |
| Reconcile cash | Prepare | Verify | Reconcile | Oversight |
| Post accounting adjustment | No | No | Yes | Controlled |
| Reverse payment | No | Request/Review | Authorized | Controlled |
| View company-wide finance | No | No | According to scope | Yes |

## Principle
High-risk financial actions require separation of duties and audit trail.
