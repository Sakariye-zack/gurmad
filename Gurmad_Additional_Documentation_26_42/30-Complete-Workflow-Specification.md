# 30. Complete Workflow Specification

## Customer onboarding
Admin/authorized staff → Create customer → Register house → Assign zone → Capture GPS → Activate service.

## Operational setup
Create zone → Register trucks → Register drivers/collectors → Assign teams → Assign trucks to zone.

## Daily collection
Review unserviced/due houses → Check truck capacity → Create batch → Assign truck/driver/collector(s) → Generate route → Collector starts → Mark houses serviced/missed → Complete task → Store history.

## Payment
Serviced customer → Cashier sees assigned portfolio → Open invoice → Customer pays Cash/ZAAD/eDahab → Confirm payment → Update balance → Generate receipt.

## Debt
Partial/no payment → Outstanding balance → Cashier debt list → Future collection → Payment reduces balance.

## Cashout
Cashier closes collection → Submit cashout → Head of Cashiers reviews → Variance check → Approve/reject → Sign → Download/upload → Archive → Accounting/reporting.

## Management
Admin dashboard → monitor operations, fleet, customer service, finance and exceptions.
