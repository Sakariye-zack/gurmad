# 35. Mobile App Specification

## Collector
Login → Today's tasks → Route → House list → Navigate → Service/Missed → Sync → Completion.

No financial data.

## Driver
Login → Assigned truck → Today's route → Navigation → Truck status → GPS → Task progress.

## Cashier
Login → Assigned customers → Search → Invoice → Payment → Receipt → Debt → Cashout.

## Customer
Login → Home → Invoices → Pay → Receipts → Complaints → Notifications → Account.

## Offline
Collector/driver can cache assigned operational tasks and sync when online. Financial posting requires safe server confirmation and duplicate protection.
