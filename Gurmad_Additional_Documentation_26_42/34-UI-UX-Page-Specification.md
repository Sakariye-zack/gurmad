# 34. UI/UX Page-by-Page Specification

## Admin Dashboard
KPIs, revenue, expenses, outstanding debt, active tasks, trucks, collectors, cashiers, alerts and live map.

## Zones
Zone list → details → customers → houses → trucks → staff → tasks → reports.

## Customers
Search, filters, profile, house, GPS, service history, invoices, payments, debt and documents.

## Collection Tasks
Create batch, select zone, capacity, truck, driver, collector(s), houses and route.

## Operations Map
Filters for zone, truck, task, status and date. Map plus detail panel.

## Cashier
Customer search, invoice, balance, payment method, amount, receipt and debt list.

## Head of Cashiers
Cashier list, submitted cashouts, expected/actual, variance, approval and documents.

## Accounting
Dashboard, accounts, journals, ledger, AR, AP, Trial Balance, P&L, Balance Sheet and Cash Flow.

## Documents
Invoices, receipts, quotations, cashouts, approvals, signed uploads and archive.

## Design
Preserve Gurmad logo/colors; improve spacing, hierarchy, tables, forms, responsive behavior and empty/error states.
